## 📖 Abstract

This repository contains raw data and MATLAB executable codes for the manuscript titled **"Solid-State Optical Magnetometer: A Next-Generation Approach to Sub-Nanotesla Magnetic Sensing."** The dataset includes simulated absorption spectra obtained from a metasurface-integrated black phosphorus structure, exposed to s- and p-polarized light under different currents (50, 100, and 200 µA). Leveraging the unique linear dichroism properties of black phosphorus, this solid-state magnetometer achieves precise, sub-nanotesla magnetic sensing. The provided data and analysis scripts facilitate replication, further analysis, and validation of the described results.

---

## 🗂️ Data Organization

The repository structure includes separate folders for each current setting:

- 📁 **50 µA**: Contains raw Excel data and corresponding MATLAB `.m` analysis scripts.
- 📁 **100 µA**: Contains raw Excel data and corresponding MATLAB `.m` analysis scripts.
- 📁 **200 µA**: Contains raw Excel data and corresponding MATLAB `.m` analysis scripts.

Each Excel file is structured in two columns:
- **Column 1**: Wavelength (nm)
- **Column 2**: Spectral data (absorption values)

---

## 🛠️ Methodology & Usage

The dataset was generated using Finite Element Method (FEM) simulations. Data files can be accessed using Excel, while the provided analysis scripts are executable on MATLAB platforms.
